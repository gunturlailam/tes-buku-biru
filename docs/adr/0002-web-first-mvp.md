# ADR 0002 — Web-first MVP and shared frontend ownership

- Status: Proposed
- Decision owner: Risfiatul, Ronal, Hanif
- Context: Current team assignment identifies two UI/UX frontend owners but does not explicitly confirm mobile as a required MVP deliverable.
- Decision: Build and stabilize one frontend application first. Ronal owns shared design system/app shell/dashboard/transaction experience; Hanif owns report/insight/recommendation feature modules and integration QA.
- Consequences: Avoid splitting into separate web/mobile apps until product requirement and hackathon criteria justify it. Both frontend members coordinate shared files and use one component system.
