# Task Ownership — Risfiatul (Lead / Product / AI-ML)

## Mission
Keep ProfitAI coherent, useful, measurable, and technically honest. Own product decisions and AI/financial methodology.

## Primary ownership
- PRD, scope, priorities, acceptance criteria.
- Financial and AI methodology approval.
- Risk signal definitions and threshold validation plan.
- Forecasting evaluation and release gates.
- Recommendation logic and LLM explanation policy.
- Sprint planning, cross-team dependencies, release readiness.

## Phase 0 tasks
- [ ] Review PROGRAM, PRD, ARCHITECTURE, METHODOLOGY with all members.
- [ ] Confirm MVP scope and open decisions in DECISIONS.md.
- [ ] Inspect hackathon brief/rubric; map requirements without assuming.
- [ ] Define demo user journey and success criteria.
- [ ] Approve metric definitions and data-quality labels.

## Phase 1 tasks
- [ ] Define business profile and industry context.
- [ ] Agree transaction taxonomy and account mapping with Guntur.
- [ ] Write recommendation rule catalogue with evidence requirements.
- [ ] Prepare synthetic, clearly labeled demo scenarios.
- [ ] Define forecast target/horizon and evaluation report format.

## Phase 2+ tasks
- [ ] Review calculation fixtures and edge cases.
- [ ] Validate risk thresholds against representative data or document provisional status.
- [ ] Build/evaluate naive and candidate forecasts using walk-forward validation.
- [ ] Implement recommendation service/LLM adapter only after evidence contract exists.
- [ ] Review output hallucination, privacy, and schema validation.
- [ ] Approve release only when gates are met.

## Must coordinate with
- Guntur: domain model, financial engine, API and model deployment.
- Ronal: KPI definitions, warning labels, recommendation content.
- Hanif: report/forecast/insight experience and user feedback.

## Do not
- Change API schema unilaterally.
- Claim forecast accuracy without backtest.
- Make LLM calculate financial numbers.
- Add features outside agreed MVP without reprioritization.

## Deliverables
Approved PRD/methodology, decision log, rule catalogue, forecast evaluation results, product acceptance sign-off.
