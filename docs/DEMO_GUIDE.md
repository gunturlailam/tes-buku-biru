# Demo Guide — ProfitAI

## Demo narrative
1. Introduce the problem: financial data exists but is difficult to interpret.
2. Show business profile and transaction entry/import.
3. Show categorized transaction list.
4. Show dashboard with selected period and data-quality label.
5. Open a metric to explain formula and source.
6. Show risk signal and evidence.
7. If forecast passed validation, show forecast with horizon and evaluation caveat. Otherwise show honest "data not sufficient / forecast not enabled" state.
8. Show recommendation and suggested next action.

## Demo data
- Use synthetic business data only.
- Clearly label it as simulated.
- Include normal and edge-case scenarios.
- Do not use real customer names, bank account numbers, tax IDs, or private transaction descriptions.

## Demo integrity
- Never claim SAK compliance without verification.
- Never claim model accuracy unless the evaluation report supports it.
- Do not hide warnings or manually change values during demo.
- Prepare fallback screenshots/video only if live environment fails, and label them appropriately.
